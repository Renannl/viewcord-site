Instalação automática

Abra o PowerShell, cole este comando e pressione Enter.

iwr -useb https://raw.githubusercontent.com/Renannl/Viewcord/main/install.ps1 | iex
O script baixa e instala a versão mais recente. Ou baixe manualmente ↗
Dúvidas comuns

Perguntas frequentes.

O Viewcord substitui a call do Discord?

Não. O Viewcord é usado para compartilhar a tela; você pode continuar conversando na call do Discord.

Em quais sistemas funciona?

O instalador disponibilizado atualmente é para Windows.

O app é gratuito?

Sim. O projeto é gratuito e o código está disponível no GitHub.

Como reporto um problema?

Abra uma issue no repositório do Viewcord no GitHub e descreva o que aconteceu.
